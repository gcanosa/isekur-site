# isekur-site

The website of [iSekur](https://github.com/gcanosa/iSekur), served by GitHub Pages at https://gcanosa.github.io/isekur-site/.

`e65bc1d0bf758e2c8e2f311d154aff2d.txt` is the IndexNow key (Bing, Yandex): after a big change, `curl "https://api.indexnow.org/indexnow?url=https://gcanosa.github.io/isekur-site/&key=e65bc1d0bf758e2c8e2f311d154aff2d&keyLocation=https://gcanosa.github.io/isekur-site/e65bc1d0bf758e2c8e2f311d154aff2d.txt"`.

`themes.json` is generated from iSekur's `themes/*.theme` files; regenerate it when themes change: `python3 gen-themes.py ../iSekur/themes > themes.json`.
